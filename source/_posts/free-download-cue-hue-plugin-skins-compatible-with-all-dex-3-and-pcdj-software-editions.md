## Free Download: Cue Hue Plugin Skins Compatible with All DEX 3 and PCDJ Software Editions

Often a little tweak to an existing design can made a big difference.

We believe that’s the case for the recently submitted CUE HUE Skin, a 2-deck (with tablet mode) color-modified version of the [DEX 3 RE](https://tools.techidaily.com/pcdj/products/) default [GUI](https://en.wikipedia.org/wiki/Graphical%5Fuser%5Finterface). Instead of usual grey tones for the on-screen waveform’s, VU meters and various knobs found in DEX 3 RE, the DJ/designer used a cool blue and a dark-tonal red to further define each deck.

[VIEW LARGER IMAGE ![Cue Hue Skin For DEX 3 DJ Software](https://i2.wp.com/pcdj.com/wp-content/uploads/2016/07/dex-cue-hue-skin-screenshot.jpg?fit=300%2C169&ssl=1 "Cue Hue Skin For DEX 3 DJ software")](https://i2.wp.com/pcdj.com/wp-content/uploads/2016/07/dex-cue-hue-skin-screenshot.jpg?fit=1030%2C579&ssl=1)

The DJ edited the DEX 3 RE default skin file (a .png file) by opening it in Photoshop and edited directly, as opposed to using our [free Skin Designer](https://tools.techidaily.com/pcdj/products/) software. The designers method allows you to easily modify an existing skin by adjusting hue and color but for more advanced skinning such as a total modification and customization of features and layout DJs should use Skin Designer. If you can dream it up and have the graphical prowess to create it you can map it with [Skin Designer](https://tools.techidaily.com/pcdj/products/) for use with all DEX 3 versions.

The CUE HUE skin can be downloaded (for free, as always) below and used with [DEX 3 (Pro Edition)](https://tools.techidaily.com/pcdj/products/), DEX 3 RE and our [free DJ software](https://tools.techidaily.com/pcdj/products/) – DEX 3 LE.

[DOWNLOAD CUE HUE SKIN FOR ALL VERSIONS OF DEX 3](https://tools.techidaily.com/pcdj/products/)

**NOTE:** Unzip the contents of the zip file to Documents -> PCDJ-DEX3 (or PCDJ-DEX3LE, PCDJ-DEX3RE) -> Skins. Then you can select and enable the skin in DEX 3’s options under the “select user interface” drop-down menu under the general tab.
